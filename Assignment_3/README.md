# Assignment 3 – Introduction to Programming

## Course

EE1102 – Introduction to Programming

## Objective

This assignment introduces iteration using `for` and `while` loops through character processing, digit manipulation, and numerical approximation using the Taylor series expansion of the natural logarithm.

## Learning Outcomes

After completing this assignment, I learned to:

- Use `for` and `while` loops effectively
- Work with ASCII characters
- Extract digits using the modulus operator
- Perform iterative numerical computations
- Implement mathematical series approximations

## Files

| File | Description |
|------|-------------|
| ee19b108_alph.c | Prints the lowercase English alphabet separated by commas. |
| digit.c | Decomposes an integer into its digits based on decimal place values. |
| taylor_series_log.c | Computes an approximation of `ln(1+x)` using the first ten terms of the Taylor series. |

## Concepts Covered

- For Loops
- While Loops
- ASCII Character Encoding
- Modulus Operator (`%`)
- Taylor Series
- Numerical Approximation
